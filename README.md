# Leechfin Hero

Leechfin Hero adds Guitar Hero-inspired visuals and scoring to Leechfin Fishing in Old School RuneScape.

## Features

- Colored leechfin projectiles for each fishing lane
- Guitar Hero-style fret rings
- Hit flame effects when facing the correct fishing spot
- Cyan "Star Power" effects for dropping fish from inventory mid-wave
- Note streak tracking
- Streak multipliers:
    - x1: 0-10 notes
    - x2: 11-20 notes
    - x3: 21-29 notes
    - x4: 30+ notes
- Persistent high score
- Persistent highest note streak
- Reset options in the plugin configuration

## Scoring

Each leechfin awards points equal to the Fishing XP gained, multiplied by the current streak multiplier.

Both successful catches and failed catches that award Fishing XP count toward the note streak. Facing the wrong fishing lane breaks the streak.

## Credits

Based on the original Leechfin Fishing plugin by Andrew Scherer.
